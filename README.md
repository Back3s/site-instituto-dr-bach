# Site do Instituto Dr. Bach

Site institucional e de captação de alunos do **Instituto de Desenvolvimento Humano Dr. Bach** (cursos de saúde bucal e 2ª licenciaturas). Site estático em português: HTML, CSS e JavaScript, sem servidor.

- Abra `index.html` para ver o site.
- `LEIA-ME.md`: como editar conteúdo, trocar fotos e cores.
- `PENDENCIAS.md`: o que ainda falta o instituto enviar ou confirmar.
- `ASSETS.md`: lista das imagens usadas e dos tamanhos ideais.
- `_fonte/`: código que gera as páginas (não faz parte do site publicado).

As fotos atuais são provisórias.
